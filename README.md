# מילה – מילון אנגלית ↔ עברית אופליין

אפליקציית Android פשוטה ונעימה לתרגום מילים וביטויים נפוצים בין אנגלית לעברית, ללא חיבור לאינטרנט.

## מה כלול
- תרגום דו-כיווני לפי מאגר מקומי.
- חיפוש תוך כדי הקלדה והצגת התאמות דומות.
- בחירת תוצאה כדי להכניס אותה לשורת החיפוש.
- ממשק בעברית, ללא הרשאת אינטרנט.
- 467 ערכים במאגר הראשוני.

## בניית APK
הפרויקט כולל GitHub Actions בקובץ `.github/workflows/android-apk.yml`. לאחר העלאת הפרויקט לענף `main`, לשונית Actions תבנה APK ותעלה אותו כ-artifact בשם `Mila-debug-apk`.

זהו מילון אופליין עם התאמות מדויקות וחיפוש חלקי, לא מנוע תרגום חופשי למשפטים.
